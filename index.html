Install on Linux

Use the install script to configure the Vaulton package source and install the native package for your distribution.

curl -fsSL https://ericg2.github.io/install.sh | sh

Debian and Ubuntu use APT, Fedora and RHEL use DNF, and openSUSE uses Zypper. Once configured, update Vaulton with your normal package manager.

Checking Linux package repository availability…

The hosted APT and RPM repositories currently use HTTPS transport but do not yet publish signed repository metadata. APT and DNF repository signature verification is therefore disabled by the installer. For higher-assurance deployments, download packages from the GitHub Releases page and verify the published SHA-256 checksum.
